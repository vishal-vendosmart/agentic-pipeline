### Lessons (durable)
1. **Zernio post updates are PUT, not PATCH.** `PATCH /posts/{id}` returns 405 empty body. `PUT /posts/{id}` with `{content:...}` returns 200 and preserves scheduledFor/status. Old script `update_thread.mjs` uses PATCH and is therefore broken.
2. **Do not probe a live endpoint with write methods.** I probed PATCH/PUT/POST on Post 2's real id and PUT overwrote its content with `__probe__`. Caught and restored within the same step, but the correct move is to probe on a throwaway id or read the API spec first.
3. **Writer subagent reported `EmbeddedAttemptSessionTakeoverError` (deliveryStatus: failed) but BOTH output files were written correctly.** Treat writer delivery-status failure as a warning, then verify the artifacts on disk before re-running. Re-spawning would have wasted the work.
